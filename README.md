## Conventions de nommage

| Élément | Convention | Exemple |
|---|---|---|
| Types (classes, structs, enums, `using`) | `PascalCase` | `ScreenTri` |
| Fonctions | `camelCase` | `renderTile()` |
| Variables locales et paramètres | `camelCase` | `tileIndex` |
| Membres | `camelCase` avec marqueur `_` | `mat_` |
| Constantes | `camelCase` | `maxParticles` |
| Namespaces | minuscules | `renderer` |
| Macros | `UPPER_SNAKE_CASE` | `COLOR_CLEAR` |
| Templates | `T` ou `PascalCase` descriptif | `ValueType` |
| Booléens | préfixe qui se lit comme une question | `isAlive` |
